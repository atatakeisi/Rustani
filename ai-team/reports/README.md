# Codexへの調査結果

更新日: 2026-10-24（日本時間）。現在の体制はCodex + AntigravityのGemini。CodexがRustの設計・実装・検証・統合を担当し、AntigravityのGeminiは `ai-team/tasks/` を直接読んで、依頼された調査・レビューの結果をここへ書く。Gemini CLI・Claude CLIは使用しない。

現在の指定と完了状況は `ai-team/tasks/README.md` を参照する。完了済み依頼を自動再開せず、Codexまたは人間から指定された1件だけを進める。

1回の依頼につき、実際の作成日時を含む一意な名前の新しいMarkdownファイルを1つ作成する（例: `gemini-browser-YYYYMMDD-HHMMSS.md`）。同じ名前がすでにあれば別名を選び、実際の保存先を報告する。既存レポート・ソースコード・他担当のファイルは編集しない。

Geminiはソースや既存文書を変更せず、Cargo/rustc/Trunk/テスト/ベンチマークを実行しない。環境変数変更・ファイル削除・ディレクトリ上書き・パッケージ操作・別AI/CLI起動も行わない。必要な検証はCodexへの依頼として記す。実行していない検証は「未実施」と明記し、Codexの結果を自分の実施結果として扱わない。

レポート形式:

```markdown
# 担当 / 調査テーマ
- 日時・担当AI:
- 対象commit・作業ツリーの変更有無:
- 読んだ範囲:
- 実行した検証 / 未実施の検証:

## 結論（上位3件まで）
### 1. 問題または改善候補
- 種別: 再現済み / コードで確認 / 仮説・未検証
- 根拠: path:line、または公式URLと確認日
- 再現条件: ブラウザ/OS/入力/操作（未実施ならその旨）
- 最小変更案: 変更候補ファイル・関数、目的
- 副作用・設計上の注意:
- Codexが実行する検証手順・合格条件:

## 残る不明点 / Codexへの依頼
```

完了したら人間へ相対パスを伝える。人間はCodexのチャットへ
「`ai-team/reports/` の新しいレポートを読んで、優先順位を決めて実装して」と送る。
Codexは指摘を現行コードで確認し、実装・検証・PROJECT_STATUS.md更新を行う。
